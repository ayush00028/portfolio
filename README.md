# Krishna Kumar - Developer Portfolio

> **Notice:** This repository contains the source code and structural foundation for my personal developer portfolio website. Real-world projects, verified technical skills, and background details are being curated and updated progressively.

A modern, responsive, and interactive developer portfolio featuring 3D Three.js graphics, dark/light theme support, and enterprise-grade frontend security hardening.

---

## Overview & Highlights

- **Interactive 3D Visuals**: Responsive 3D quantum core and orbital particles powered by Three.js that track cursor movement and adapt dynamically to theme modes.
- **Developer Experience**: Interactive developer command terminal (press `Ctrl + K` or `Cmd + K`), real-time project filtering and search, and native Web Audio sound synthesis.
- **Tactile Micro-Interactions**: Dynamic 3D perspective card tilt with ambient spotlight reflections.
- **Enterprise Security**: Content Security Policy (CSP), anti-bot honeypot, XSS input sanitization, 30s rate limiting, and clickjacking protection (`X-Frame-Options: DENY`).
- **Dark / Light Theme**: Smooth theme switcher with local storage persistence and system preference detection.
- **Accessibility & Quality**: Built with modular components, semantic HTML, and accessibility compliance (`prefers-reduced-motion`).

---

## Built With

- **Frontend**: [React](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **3D Graphics**: [Three.js](https://threejs.org/)
- **Icons**: [Lucide React](https://lucide.dev/)

## Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/ayush00028/portfolio.git
cd portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start local development server
```bash
npm run dev
```

Open `http://localhost:3000` to view the website locally.

### 4. Build for production
```bash
npm run build
```
